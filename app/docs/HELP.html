Part 1 · Using the program

Getting started

  1. Before unzipping the downloaded zip, right-click it > Properties > tick Unblock. Then unzip it to a folder you can write to, for example D:\Tools\SecureOfflineTranscriber (not C:\Program Files).
  2. Optional: run verify-files.bat. It checks that every file arrived complete (antivirus programs sometimes block a file while unzipping).
  3. Double-click run.bat. create-shortcut.bat adds shortcuts on the desktop and in the Start menu; to pin the program to the taskbar, start it, right-click its taskbar icon and choose Pin to taskbar.
  4. At the first start no speech model is installed yet. Choose Download recommended set: Whisper small (486 MB), or Whisper large-v3-turbo (1.6 GB) on a PC with 12 GB of memory or more. If you also transcribe Cantonese or Mandarin, tick I also transcribe Cantonese or Mandarin to add SenseVoiceSmall (240 MB). Or choose Add a model folder if you already keep models somewhere, for example the local_whisper folders of version 2.0.

The window has three parts: Media input at the top (file, Transcribe button, queue, player), the Transcript and Raw output tabs in the middle, and the status line and statistics bar at the bottom. The title bar shows the program name and version, for example Secure Offline Transcriber (2.1.4), and the progress while a job runs.

Transcribe a recording

  1. Open a file with File > Open Media (Ctrl+O), the Open… button, or by dropping it on the window. WAV, MP3, M4A, FLAC, OGG, MP4, MKV, MOV and most other audio and video files work. The info line shows format, length, sample rate, channels and size; a video with several audio tracks shows a track list.
  2. Check the button. The Transcribe button says which model and language will be used, for example Transcribe – Automatic (SenseVoiceSmall int8) · Auto-detect. Change them in the Transcribe menu (Language, Model) if needed.
  3. Press Transcribe or F5. Text appears as each piece is finished. The status line shows the stage and time left; the statistics bar shows time used, audio done and speed.
  4. Results are saved automatically to the output folder (Documents\SOT Transcripts unless you changed it): the session file .sot.json plus Text with times and SRT subtitles.

Several files: open or drop two or more files and a queue appears. They run one after another; each result is saved before the next starts, and a file that fails is marked Failed while the queue goes on. Use Remove, Move up and Move down to arrange it before you press Transcribe.

What happens inside: ffmpeg.exe reads the audio (and applies noise reduction if you chose it), quiet recordings are raised to a normal level, voice detection finds the speech and skips silence, the model writes the text, then the clean-up removes invented phrases, applies your vocabulary replacements and converts Chinese to the script you chose.

Stop and resume a long job

Stop (Esc or the button) keeps the text done so far and saves it. The button then reads Resume from hh:mm:ss: press it (or F5) and the job carries on from the end of the text, with the same model and language, instead of starting again. Corrections you made to the text in between are kept. When it finishes, the same transcript and export files are updated (no "(2)" copies), and the statistics show the totals of all runs.

  • After a crash or power cut: the text is saved every few seconds while a job runs. At the next start the program offers Resume transcribing, Show the text only or Discard.
  • Later: open the saved transcript with File > Open Transcript; if it was stopped, the button offers Resume.
  • From the beginning: Transcribe > Start Again from the Beginning replaces the text on screen (saved files are kept).
  • If the model used before is no longer available, the program asks whether to carry on with another one.

Proofread and correct

Checking a transcript against the recording is usually the slowest part of the work. The player and the transcript work together:

  • Follow playback (the Follow button, on by default): while the audio plays, the paragraph is tinted and the sentence being spoken is highlighted, and the transcript scrolls so it stays in view. If you scroll or type, following pauses for a few seconds so the text does not jump away from you.
  • F9 plays or pauses at any time, even while you type in the text (Space also works when the cursor is not in the text).
  • F6 replays the current sentence. Pressed again within the first second of a sentence, it goes back one more. When the audio is paused, it plays the sentence where your text cursor is.
  • F8 / F7 jump to the next / previous unsure line: lines Whisper was not sure about are tinted amber. The sentence is selected (so you can type over it) and played. SenseVoiceSmall, Parakeet and Moonshine do not report how sure they are, so their transcripts have no amber lines.
  • Click a time to play from that paragraph, or Ctrl+click any word to play its sentence.
  • Playback speed (the 1× list next to the player, or Transcribe > Playback Speed): 0.5×–1.5× with natural pitch. 0.75× helps with fast speakers.
  • Ctrl+Left / Ctrl+Right skip 5 seconds when the cursor is not in the text.

Correct words directly in the Transcript tab. For a word that is wrong everywhere, use Edit > Replace (Ctrl+H), or select it and choose Edit > Add Selection to Vocabulary so it is fixed in future files too.

Names from your documents

Whisper writes names it has never heard as best it can ("Marta Quinteiro" becomes "Martha Kintero"). Hotwords tell Whisper which names to expect. Instead of typing them, take them from the meeting's paperwork:

  1. Edit > Add Names from Documents…, or in Options > Vocabulary Names from documents… / Names from pasted text….
  2. Choose an agenda, attendee list or e-mail: Word (.docx), Excel (.xlsx), PDF with text, text, CSV, Markdown, HTML or a saved e-mail (.eml). For an Outlook e-mail, copy its text and use Paste text….
  3. The dialog lists the people, organisations and special terms found, with how often each appears and why it was picked (attendee list column, e-mail sender, capitalised name, special spelling). Suggested ones are ticked; untick anything that is not a name, double-click to correct a spelling.
  4. Choose the vocabulary set (or a new one, for example "Annual conference 2026"), then Add to vocabulary.
Hotwords help Whisper only. A set's hotwords are used up to about 100 words; names further down are not used, so keep the names of the coming meeting first and remove old ones. Too many unusual hotwords can make Whisper insert them where they were not said; if that happens, shorten the list.

Names are found with simple rules on this PC, not by an AI service: Word tables and Excel columns headed Name, First name, Last name, Company or Organisation give the best results; a PDF loses its table layout, so check its suggestions more carefully.

Noisy recordings

For recordings made in a café, on a conference floor or in a car, try Transcribe > Noise Reduction > Light. It removes rumble below the speech range and steady background noise before recognition, using filters built into ffmpeg.exe (nothing to download; it adds roughly 20 seconds per hour of audio).

  • Off (default) for clean recordings: filtering clean speech can lose quiet words or change a few.
  • Light for steady background noise (air conditioning, crowd murmur, traffic).
  • Strong for loud steady noise; it can make voices sound thin and cut soft syllables.
  • Tick Hear It in the Player to listen to the cleaned audio before you transcribe. Compare a minute with and without it: if the text does not get better, leave it off.

Noise reduction cannot separate overlapping voices or remove music and loud chatter close to the microphone.

Save and export

After each job the program saves the session (.sot.json) and the default formats. A session keeps the recording's path and fingerprint, the text with your edits, the statistics and the settings used; open it again with File > Open Transcript. File > Save Transcript (Ctrl+S) saves your edits. File > Export… (Ctrl+E) writes any of the eight formats from the edited text:

FormatContent and use
Text with times (.txt)[00:04:26] So the first one… per paragraph or segment; an optional header with file, date, length, language, model and statistics.
Plain text (_plain.txt)Paragraphs only, for pasting into minutes or e-mails.
Subtitles (.srt)One cue per segment; long ones split at punctuation to the subtitle limits. For video players and YouTube.
WebVTT (.vtt)As SRT, for web players and Teams or Stream uploads.
Word (.docx)Title, details table and transcript with bold times.
Markdown (.md)Heading, details list and paragraphs with times, for notes apps.
JSON (.json)Every segment with start, end, text, language and an "unsure" flag, plus statistics; for other programs.
CSV (.csv)One row per segment (index, start, end, duration, text); opens in Excel with Chinese intact.

Subtitles, JSON and CSV are written per segment; a paragraph you edited is written as one entry so your correction is not lost.

Privacy

  • Audio and transcripts never leave this PC. There is no account, analytics, crash reporting or update server.
  • The network is used only to download a model you chose; Options > Offline Mode blocks even that. It switches on by itself once a model is installed.
  • Settings, logs, temporary files and the job journal stay in the data folder inside the program folder (or the folder you chose). Logs hold file names and timings, never transcript text, and are kept 7 days.
  • Options > Advanced > Privacy check lists all of this for your PC.

Troubleshooting

What you seeWhat to do
"Some program files are missing" at startUnzipping was incomplete, often because antivirus blocked a file. Delete the folder, unzip again (7-Zip is the most reliable) and run verify-files.bat. Windows Security > Protection history shows any file it blocked.
Windows SmartScreen "Windows protected your PC"Unblock the zip before unzipping (Properties > Unblock), or choose More info > Run anyway. The only programs in the folder are the signed python.exe / pythonw.exe and the unmodified ffmpeg.exe.
Nothing happens on startRun run-debug.bat and read the console; the log is in data\logs. smoke-test.bat checks every library.
"No installed model can transcribe…"Download a model for that language in Options > Transcription, or choose another language.
Text invented in silenceKeep the invented-text filter on, add the phrase to its list; raise the speech threshold to 0.6.
Words missing in a quiet recordingKeep Normalise volume on; lower the speech threshold to 0.35–0.4; try a larger Whisper model or Accurate speed.
Names misspelledAdd them as hotwords (Whisper) or replacements (all models); see Names from documents.
Slow on a long fileUse SenseVoiceSmall or Parakeet, Fast speed, background priority off; Stop and Resume if you need the PC.
A word repeated where a job was resumedThe program removes a repeated word at the join (listed in Raw output); correct any that remain by hand.
Playback is silentCheck the Windows default output device; playback uses PortAudio. Untick Hear It in the Player if the cleaned audio is too quiet.
A downloaded model shows "Damaged"Delete it and download again; the program checks every file, so a broken download is never used.

For support, use Options > Advanced > Copy diagnostic summary; it holds no transcript text.
